# R dependencies

- `example1.R`, `example2.R`, and `example2b.R`: base R (plus recommended standard packages).
- `simulation_sandwich.R`: `ggplot2`, `dplyr`, `parallel` (last is included with standard R).
- `fig_s4_barrier.R`: `ggplot2` and optionally `gridExtra` for a combined two-panel figure.

Install in advance using an R package manager; scripts do not install packages at runtime.
Record `sessionInfo()` when preparing the final journal supplement.
